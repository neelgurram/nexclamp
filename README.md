# NeuroSem

**Does an edited neuron model still behave like the original?**

NeuroSem is a research framework and empirical study for detecting *silent behavioural
drift* in computational neuron models: edits, translations, refactors or repairs that
leave a model file valid and runnable, and even pass one standard test, while changing
how the model responds to other electrical stimuli.

> Status: under construction (pre-pilot). No scientific results exist yet.
> See `PLAN.md` for milestones and `DECISIONS.md` for open decisions.
